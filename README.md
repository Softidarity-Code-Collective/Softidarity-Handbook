# Softidarity handbook

Softidarity is a developer collective writing software for organisations working on ecology, animal
rights and human rights. This repository holds the documents we work by.

*На български по-долу.*

## What is here

| File | What it is |
|---|---|
| [values.bg.md](values.bg.md) | Our values, the Bulgarian original |
| [values.en.md](values.en.md) | The same values in English |

## How it changes

- We edit in a working document, where commenting and discussion are easy. What lands here is the
  version we have agreed on.
- One commit per meaningful change, with a message saying what changed and why.
- Any member can propose a change at any time. Changing the values requires agreement between
  members.
- Twice a year each of us rereads the document and proposes at least one change or one deletion. A
  list nobody argues with has become wallpaper.

## What does not belong here

Money, prices, offers, client details and personal data. Those do not belong in a public repository.

# Наръчник на Softidarity

Softidarity е колектив от разработчици, който пише софтуер за организации в областта на екологията,
правата на животните и правата на хората. Това хранилище държи документите, по които работим.

## Какво има тук

| Файл | Какво е |
|---|---|
| [values.bg.md](values.bg.md) | Ценностите ни, оригинал на български |
| [values.en.md](values.en.md) | Същите ценности на английски |

## Как се променя

- Редактираме в работен документ, където коментарите и обсъждането са лесни. В хранилището влиза
  версията, по която сме се съгласили.
- Един комит за една смислена промяна, със съобщение, което казва какво се променя и защо.
- Всеки член може да предложи промяна по всяко време. Промяна в ценностите изисква съгласие между
  членовете.
- Два пъти в годината всеки прочита документа и предлага поне една промяна или едно премахване.
  Списък, който никой не оспорва, е станал тапет.

## Какво не влиза тук

Пари, цени, оферти, данни за клиенти и лични данни. Те не стоят в публично хранилище.
